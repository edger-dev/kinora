# Spec — a dynamic collection stores a small metadata predicate

**Contract.** A kinograph may hold a predicate instead of (or beside) its
listed entries: a styx expression over kino metadata fields — `eq`, `range`,
`prefix`, `has`, combined with `and`, `or`, `not`. Metadata only: no
full-text terms in v1. kinora evaluates a predicate in Rust over a root's
entries; kura translates the same predicate into its local index's query
language. Backup rules ("proxies of starred") are predicates too.

**Why.** Dynamic albums and replication rules must be stored in the ledger,
readable there, and evaluable by more than one engine.

**Rejected.** A SQL subset (ties stored filters to one engine and dialect).
Tags and date ranges only (too narrow; would need extending).

**Escape hatch.** Full text, or operators beyond these, are new predicate
forms added later; an evaluator refuses a form it does not know rather than
match nothing.
